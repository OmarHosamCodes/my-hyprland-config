# My Hyprland Configuration

This repository contains my personal configuration files for [Hyprland](https://hyprland.org/), a dynamic tiling Wayland compositor.

## Repository Structure

The repository is organized as follows:

- **animations/**: Directory containing animation configurations.
- **mybash/**: Directory containing custom bash scripts or configurations.
- **themes/**: Directory containing theme configurations.
- **animations.conf**: Configuration file for animations.
- **hyprland.conf**: Main configuration file for Hyprland.
- **keybindings.conf**: Configuration file for custom keybindings.
- **monitors.conf**: Configuration file for monitor settings.
- **nvidia.conf**: Configuration file for NVIDIA-specific settings.
- **userprefs.conf**: Configuration file for user preferences.
- **windowrules.conf**: Configuration file for window rules.

## Usage

To use these configurations:

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/OmarHosamCodes/my-hyprland-config.git
   ```

2. **Navigate to the Directory**:

   ```bash
   cd my-hyprland-config
   ```

3. **Backup Existing Configurations**: It's advisable to back up your current Hyprland configuration files before making any changes.
4. **Apply Configurations**: Copy the desired configuration files to your Hyprland configuration directory, typically located at `~/.config/hypr/`.

   For example:

   ```bash
   cp hyprland.conf ~/.config/hypr/
   ```

5. **Restart Hyprland**: For the changes to take effect, restart your Hyprland session.

## Customization

Feel free to modify these configuration files to suit your preferences. Refer to the [Hyprland Wiki](https://wiki.hyprland.org/) for detailed information on configuration options and customization.
